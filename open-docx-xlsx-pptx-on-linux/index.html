How to open DOCX, XLSX and PPTX files on Linux

Microsoft Office does not run on Linux, but you can still open and edit Word, Excel and PowerPoint files. PulseOffice reads and writes DOCX, XLSX and PPTX, and it runs on any modern Linux distribution as a single AppImage.

1. Download the AppImage

Get the file for your processor from the latest release: x86_64 for most PCs, aarch64 for ARM machines.

2. Make it executable and start it

In a terminal, in the folder where you saved it:

chmod +x PulseOffice-*.AppImage && ./PulseOffice-*.AppImage

On the first start PulseOffice offers to add itself to the applications menu and to open your Office files by default. It also updates itself when a new version comes out.

3. Open your files

  • Word documents (.docx) open in Folio.
  • Excel workbooks (.xlsx) open in Ledger, with formulas, charts and pivot tables.
  • PowerPoint presentations (.pptx) open in Deck, with layouts, transitions and animations.

You can save back to the same format, or to the open OpenDocument formats (ODT, ODS, ODP) that PulseOffice uses by default. If something in your file cannot be stored in the format you choose, PulseOffice tells you before saving.

Works on every distribution

The AppImage bundles everything it needs, so it runs on Fedora, Ubuntu, Debian, Linux Mint, Arch, openSUSE and others without installing packages.

Mit Sorgfalt gebaut

Offene Formate, keine stillen Überraschungen.

PulseOffice schreibt seinen eigenen OpenDocument- und Office-Open-XML-Code. Wenn ein Dateiformat etwas nicht aufnehmen kann, sagt es Ihnen das vor dem Speichern, statt es stillschweigend zu verwerfen.

Zuerst ODF, Office im Einklang

OpenDocument ist der Standard. DOCX, XLSX und PPTX werden mit denselben Funktionen geschrieben und gelesen, oder der Verlust wird gemeldet.

Signaturen und Verschlüsselung

Digitale Signaturen in ODF, OOXML und PDF, Verschlüsselung mit Passwort und OpenPGP, automatisches Entfernen von Metadaten.

Makros in JavaScript und Python

Ein integrierter Editor mit Vervollständigung und Makrorekorder. Makros laufen in einer Sandbox: keine Dateien, kein Netz, keine Prozesse, außer Sie erlauben es.

Objekte, die reisen

Kopieren Sie ein Diagramm, eine Tabelle, eine Form oder einen Zellbereich von einer App in eine andere, und es bleibt bearbeitbar.

Fünf Sprachen

Englisch, Italienisch, Deutsch, Spanisch und Französisch, einschließlich Funktionsnamen und Trennzeichen in jeder Sprache.

Wirklich plattformübergreifend

Dieselben Funktionen unter macOS, Windows und Linux, mit nativen Menüs, hellem und dunklem Design, Menüband und Befehlspalette.

Bereit für KI-Agenten

Nutzen Sie den KI-Agenten Ihrer Wahl.

Ein eingebauter Server spricht MCP, das offene Model Context Protocol: Jeder MCP-fähige Agent kann Ihre geöffneten Dokumente lesen und bearbeiten, mit denselben Werkzeugen wie die Makros. Er arbeitet über lokales HTTP oder über eine kleine stdio-Brücke für Clients, die Server als Befehle starten. Die Beispieldokumente auf dieser Seite wurden so von einem Agenten erstellt.

  • Standardmäßig aus, nur lokal, durch einen Zugangscode geschützt
  • Drei Stufen: lesen, bearbeiten, Dateien
  • Jede Änderung ist ein rückgängig machbarer Schritt, als Agent gekennzeichnet
  • Was sich nicht rückgängig machen lässt, wird vorher bestätigt

Fragen

Häufige Fragen

Ist PulseOffice kostenlos?

Ja. PulseOffice ist kostenlos und Open Source unter der Lizenz GPL-3.0, ohne Abonnement und ohne Konto.

Kann PulseOffice Word-, Excel- und PowerPoint-Dateien öffnen?

Ja. Es öffnet und speichert DOCX, XLSX und PPTX sowie die OpenDocument-Formate ODT, ODS und ODP und warnt vor dem Speichern, wenn ein Format etwas nicht aufnehmen kann.

Auf welchen Systemen läuft PulseOffice?

Linux (AppImage für x86_64 und ARM64), Windows (x64-Installer) und macOS (Apple Silicon und Intel).

Ist es eine Alternative zu Microsoft Office?

Das ist das Ziel: Dokumente, Tabellen und Präsentationen mit denselben Dateiformaten, kostenlos und auf jedem System.

Ist PulseOffice für den Alltag bereit?

Noch nicht. Es wird aktiv entwickelt: Probieren Sie es aus, melden Sie Probleme auf GitHub und sichern Sie wichtige Dokumente.

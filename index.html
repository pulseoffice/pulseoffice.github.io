Built with care

Open formats, no silent surprises.

PulseOffice writes its own OpenDocument and Office Open XML code. When a file format cannot hold something, it tells you before saving instead of dropping it quietly.

ODF first, Office aligned

OpenDocument is the default. DOCX, XLSX and PPTX are written and read with the same features, or the loss is declared.

Signatures and encryption

Digital signatures in ODF, OOXML and PDF, password and OpenPGP encryption, automatic redaction of metadata.

Macros in JavaScript and Python

An integrated editor with completion and a macro recorder. Macros run in a sandbox: no files, network or processes unless you allow them.

Objects that travel

Copy a chart, a table, a shape or a sheet range from one app to another and it stays editable.

Five languages

English, Italian, German, Spanish and French, including formula names and separators in each language.

Truly cross-platform

The same features on macOS, Windows and Linux, with native menus, light and dark themes, a ribbon and a command palette.

AI agent ready

Bring the AI agent you prefer.

A built-in server speaks MCP, the open Model Context Protocol, so any MCP-compatible agent can read and edit the documents you have open, with the same tools the macros use. It works over local HTTP or through a small stdio bridge for clients that start servers as commands. The sample documents on this page were created by an agent this way.

  • Off by default, local only, protected by an access code
  • Three levels: read, edit, files
  • Every change is one undoable step, labelled as the agent's
  • Anything undo cannot revert asks you first

Questions

Frequently asked questions

Is PulseOffice free?

Yes. PulseOffice is free and open source under the GPL-3.0 licence, with no subscription and no account.

Can PulseOffice open Microsoft Word, Excel and PowerPoint files?

Yes. It opens and saves DOCX, XLSX and PPTX as well as the OpenDocument formats ODT, ODS and ODP, and warns before saving if a format cannot hold something. See how to open Office files on Linux.

Which systems does PulseOffice run on?

Linux (AppImage for x86_64 and ARM64), Windows (x64 installer) and macOS (Apple silicon and Intel).

Is it an alternative to Microsoft Office?

That is the goal: documents, spreadsheets and presentations with the same file formats, free and on every system. See PulseOffice as a free Microsoft Office alternative.

Is PulseOffice ready for everyday use?

Not yet. It is in active development: try it, report problems on GitHub and keep backups of important documents.

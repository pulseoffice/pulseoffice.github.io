Built with care

Open formats, no silent surprises.

PulseOffice writes its own OpenDocument and Office Open XML code. When a file format cannot hold something, it tells you before saving instead of dropping it quietly.

ODF first, Office aligned

OpenDocument is the default. DOCX, XLSX and PPTX are written and read with the same features, or the loss is declared.

Signatures and encryption

Digital signatures in ODF, OOXML and PDF, password and OpenPGP encryption, automatic redaction of metadata.

Macros in JavaScript and Python

An integrated editor with completion and a macro recorder. Macros run in a sandbox: no files, network or processes unless you allow them.

Objects that travel

Copy a chart, a table, a shape or a sheet range from one app to another and it stays editable.

Five languages

English, Italian, German, Spanish and French, including formula names and separators in each language.

Truly cross-platform

The same features on macOS, Windows and Linux, with native menus, light and dark themes, a ribbon and a command palette.

AI agent ready

Let Claude work on your documents.

A built-in MCP server lets Claude Code or Claude Desktop read and edit the documents you have open, with the same tools the macros use. The sample documents on this page were created that way.

  • Off by default, local only, protected by an access code
  • Three levels: read, edit, files
  • Every change is one undoable step, labelled as the agent's
  • Anything undo cannot revert asks you first
